第3章 化学分野 → テーマ25 原子と分子，化学式，化学反応式

●水素の燃焼
2H₂ + O₂ → 2H₂O

●メタンの燃焼（有機物を燃焼させたときの例）
CH₄ + 2O₂ → CO₂ + 2H₂O

●酸化銅の炭素による還元
2CuO + C → 2Cu + CO₂

●酸化銅の水素による還元
CuO + H₂ → Cu + H₂O

●塩酸と水酸化ナトリウムの中和
HCl + NaOH → NaCl + H₂O

●硫酸と水酸化バリウムの中和
H₂SO₄ + Ba(OH)₂ → BaSO₄ + 2H₂O

●塩酸とマグネシウムの反応
2HCl + Mg → MgCl₂ + H₂

●水酸化カルシウム（石灰水）と二酸化炭素の反応
Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
