第3章 化学分野 → テーマ25 原子と分子，化学式，化学反応式

主な化学反応式

●炭酸水素ナトリウムの熱分解
2NaHCO₃ → Na₂CO₃ + H₂O + CO₂

●酸化銀の熱分解
2Ag₂O → 4Ag + O₂

●水の電気分解
2H₂O → 2H₂ + O₂

●塩酸の電気分解
2HCl → H₂ + Cl₂

●塩化銅水溶液の電気分解
CuCl₂ → Cu + Cl₂

●鉄と硫黄の化合
Fe + S → FeS

●銅と硫黄の化合
Cu + S → CuS

●銅の酸化
2Cu + O₂ → 2CuO

●炭素の燃焼
C + O₂ → CO₂
