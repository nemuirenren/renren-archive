123お / ご〜願う

意味 〜してください
接続 お / ご＋N / Vます＋願う
お確かめ願う / お引き受け願う / ご変更願う

1 敷地内での喫煙はご遠慮願います。
2 質問等ございましたら、お気軽にお電話願います。
3 ご自宅に請求書をお送りいたしましたので、お確かめ願います。

124お / ご〜くださる

意味 〜してくれる（相手がしてくれたことに感謝する）
接続 お / ご＋N / Vます＋くださる
お伝えくださる / お許しくださる / ご利用くださる

1 本日はご来店くださり、誠にありがとうございます。
2 遠いところわざわざお越しくださり、ありがとうございました。
3 最後までお読みくださり、誠に感謝いたします。

125お / ご〜いただく

意味 〜してもらう
接続 お / ご＋N / Vます＋いただく
ご来店いただく / お集まりいただく / ご紹介いただく

1 本日は、お忙しい中お集まりいただき誠にありがとうございます。
2 当館では、大自然の中でゆっくり温泉をお楽しみいただけます。
3 数には限りがございますので、ご理解いただきたく存じます。
